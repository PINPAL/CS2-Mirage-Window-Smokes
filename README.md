> # Counter Strike 2
> ## Mirage Instant Window Smokes

# Installation

1. Download the latest release of the practice config [here](https://github.com/PINPAL/cs2-window/releases/latest/download/mirageSmokes.cfg)
2. Open Steam
3. Right click CS2 and click `Properties`
4. Navigate to the `Installed Files` tab on the left sidebar
5. Click the `Browse` button located on the top right
6. In the window that pops up navigate to: `game\csgo\cfg`
7. Then place all of the files from this repository into that folder.
8. Launch CS2

# Usage
1. Start a practice session on Mirage
2. Join the Terrorist team
3. Open console and type `exec mirageSmokes`
4. Type any number from 1 to 9 into console to choose that spawn (see the visual in the console for what spawn is where)
5. You will be teleported into that spawn, from here you can practice your smoke
6. Press `Backspace` to respawn after throwing your smoke if you wish to try again
7. To change your spawn, open console and repeat steps 4-6.
